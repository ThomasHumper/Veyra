# Veyra

> A revolutionary language for people who got tired of normal words.

Veyra is a tiny experimental language built around **simplicity, rhythm, and controlled chaos**. It is easy to learn, fun to speak, and completely unnecessary.

## ✨ Features

- Simple vocabulary
- Minimal grammar
- Short, rhythmic words
- Extremely questionable linguistic decisions
- No prior experience required
- 100% revolutionary*

\*Revolutionary status has not been independently verified.

## 🔢 Counting to 10

| Number | Veyra |
|---:|---|
| 1 | `ka` |
| 2 | `ve` |
| 3 | `tri` |
| 4 | `nox` |
| 5 | `sai` |
| 6 | `lum` |
| 7 | `dra` |
| 8 | `kei` |
| 9 | `vor` |
| 10 | `zen` |

### Example

```text
ka, ve, tri, nox, sai,
lum, dra, kei, vor, zen
```

Congratulations. You can now count in Veyra.

## 🗣️ Example Sentence

```text
Veyra ka!
Sai lum, vor zen.
Dra kei nox!
```

**Translation:**

> Hello! The future is bright. Let's cause some chaos!

## 📖 Basic Grammar

Veyra follows one important principle:

> **Verb first, chaos second, explanation never.**

For example:

```text
Lum sai.
```

can mean:

> “Bright future.”

Or:

> “The future is bright.”

Or, depending on context:

> “Someone turned on a lamp.”

Context is extremely important.

## 🧠 Philosophy

Veyra was designed around three principles:

1. **Keep it short.**
2. **Make it sound cool.**
3. **Don't explain too much.**

If someone asks why a word means what it means, simply respond:

```text
Vor zen.
```

They will probably stop asking.

## 🚀 Quick Start

Want to speak Veyra?

Start with:

```text
Ka!
```

Then learn the numbers:

```text
ka ve tri nox sai lum dra kei vor zen
```

Then combine words until something vaguely meaningful emerges.
